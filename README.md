# Idealizaci-n-y-Normalizaci-n-del-Romanticismo-en-las-Telenovelas
Esta infografía analiza cómo las telenovelas idealizan el amor romántico y normalizan conductas emocionales poco saludables, influyendo en nuestras expectativas afectivas. Invita a reflexionar sobre la diferencia entre ficción y realidad, promoviendo relaciones conscientes, equitativas y basadas en el bienestar emocional.
